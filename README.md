<h1>Бизнес-запросы (JPQL)</h1>
В классе BusinessQueryService реализовано 10 аналитических запросов:    

- rentalCountByGame — количество аренд по каждой игре. Выявляет самые популярные игры каталога.  

- getActiveRentals — список текущих активных аренд с датами возврата. Помогает отслеживать, какие коробки скоро вернутся.
  
- getTop3Winners — топ-3 клиентов по количеству побед в игровых сессиях.
 
- getGamesWithBoxCount — игры с указанием количества физических коробок. Для контроля ассортимента.
 
- getUnrentedBoxes — коробки, которые ни разу не арендовались (NOT EXISTS). Выявляет «залежавшийся» инвентарь.

- getAvgRentDurationByDifficulty — среднее время аренды в днях в разрезе сложности игры (TIMESTAMPDIFF).
  
- getAttractionsStatsByGame — статистика игротек по играм: количество посещений и общее время (LEFT JOIN).
 
- getProblematicClients — клиенты с просрочками и штрафами. Процент проблемных аренд через CASE WHEN и HAVING.
  
- getOverdueRentals — детализация просроченных аренд с количеством дней просрочки и суммой штрафа.
  
- getGamesFullStatistics — комплексная статистика по каждой игре: количество аренд, аттракций и игровых сессий через три коррелированных подзапроса.
